## 5. TRAPS FOUND TODAY (each cost real time)

- `set migration TRUE` is **silently rejected** — the server answers
  `No match for "TRUE"` and carries on with migration OFF. Booleans
  take `enabled`/`disabled`. Caught only because the console echo was
  missing between two other settings.
- **`improvement_vector` contains commas** in civ2civ3 (`"Aqueduct,
  Lake"`). Splitting on commas shifts every later index and produces
  nonsense censuses (this is where "stock builds 123 Banks and 0
  Temples" came from). Use `csv.reader`. The shipped `buildmix.py`
  already does; my ad-hoc scripts did not.
- **`buildmix.py` only matches players named `P1`, `P2`…**, so it
  silently outputs nothing on real-nation games like Europe.
- **`-d d:file.c`** (file-scoped debug) logged nothing; global `-d d`
  works. Costs a run if unnoticed.
- **Backgrounding with `&` inside a Bash tool call** gets killed when
  the call returns — leaves no output and no error. Use the harness's
  background mode, or `nohup setsid` over ssh.
- Benchmarks must run against `.worktrees/bench` (own build dir)
  while the main tree is edited, or a mid-run rebuild taints the run.
